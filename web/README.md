# BuyerBench Web Dashboard

**Prerequisites:** Node 18+

```bash
npm install          # install dependencies
npm run dev          # dev server at http://localhost:3000
npm run build        # static export → web/out/
npm run serve        # preview static build at http://localhost:3001
```

Data source: `../results/experiments/FULL-REPORT.json`
(generated by `python -m buyerbench report --experiment-dir results/experiments`)
